# Onboarding Documentation Source of Truth

## Syfte
Denna mapp etablerar projektets permanenta kunskapsbas för onboarding-applikationen. Dokumentationen är en AI-optimerad, versionshanterbar och sökbar strukturering av originaldokumentet `docs/source/Introduktion_for_nyanstalld_2026.pdf`.

PDF-dokumentet är projektets ursprungliga introduktionsutbildning och ska från och med nu betraktas som den primära verksamhetskällan. PDF-filen får aldrig ändras och används endast som referens.

## Hur dokumentationen är uppbyggd
Materialet är uppdelat i tolv kapitel som följer introduktionspärmns logik:

1. `01-introduktion.md`
2. `02-foretagsinformation.md`
3. `03-administration.md`
4. `04-friskvard.md`
5. `05-arbetsmiljo.md`
6. `06-forbattringsarbete.md`
7. `07-fackliga-fragor.md`
8. `08-ordningsregler.md`
9. `09-policy.md`
10. `10-kvittenser.md`
11. `11-larm.md`
12. `12-uppfoljning.md`

Varje fil innehåller:

- metadata i YAML-frontmatter
- `Syfte`
- `Lärandemål`
- `Originalinnehåll`
- tydlig markering av checklistor, tabeller, blanketter och företagsspecifika fält
- `Möjlig digitalisering`

## Hur filerna används
Markdown-filerna är inte ersättare för originalet utan arbetsdokument för:

- produktplanering
- informationsarkitektur
- framtida digitalisering
- AI-stöd i Cursor AI, Claude och ChatGPT
- sökning och versionshantering i Git
- spårbar jämförelse mellan verksamhetskrav och implementation
